Frontend HTML5

📂 ¿Qué es HTML?

HyperText Markup Language es el lenguaje estándar utilizado para estructurar el contenido de una página web mediante etiquetas.

📂 Estructura básica 
<!DOCTYPE html>
<html>
  <head>
    <title>Título</title>
  </head>
  <body>
    <h1>Hola Mundo</h1>
  </body>
</html>
📂 Elementos y Formularios

HTML permite capturar datos del usuario que luego se pueden almacenar en bases de datos mediante etiquetas como <form>, <input>, <select> y <button>.

BD Local SQLite

📂 ¿Qué es SQLite?

Es un motor de base de datos relacional ligero, basado en archivos y que no requiere un servidor independiente. Se integra directamente en la aplicación.

📂 Características principales
  • Sin configuración (Serverless).
  • Almacena toda la base de datos en un solo archivo plano (ej. database.db).
  • Ideal para aplicaciones móviles, prototipos y desarrollo escolar o local.
📂 Consulta rápida SQL 
CREATE TABLE usuarios (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre TEXT NOT NULL
);

BD Servidor PostgreSQL

📂 ¿Qué es PostgreSQL?

Es un sistema de gestión de bases de datos relacionales cliente-servidor, de código abierto, potente y enfocado en la concurrencia y extensibilidad.

📂 Características principales
  • Arquitectura Cliente-Servidor (requiere servicio activo).
  • Soporte avanzado para JSON, arrays y tipos de datos complejos.
  • Diseñado para grandes volúmenes de datos y alta concurrencia.
📂 Consulta rápida SQL 
CREATE TABLE usuarios (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
